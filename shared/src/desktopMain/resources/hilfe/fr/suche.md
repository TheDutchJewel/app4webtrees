# Rechercher, aller à, favoris

## Aller à

**Ctrl+F** (ou l'icône **Aller à**) ouvre la recherche : tapez un nom, choisissez le résultat, et la personne devient la personne centrale. Dans la disposition « Arbre au centre », Ctrl+F place le curseur dans le champ de recherche au-dessus de la liste des personnes.

## Personne de départ

**Alt+Home** saute à la personne de départ : la personne que webtrees connaît pour votre compte (votre propre enregistrement ou la personne par défaut de l'arbre). Elle sert aussi de référence pour le code couleur.

## Favoris

Gardez sous la main les personnes sur lesquelles vous travaillez : **Ctrl+D**, **Personne › Ajouter aux favoris** ou clic droit › Ajouter aux favoris. **Ctrl+B** ouvre la liste des favoris ; un clic ouvre la personne, **Retirer** l'enlève. Les favoris sont disponibles lorsque le module serveur api4webtrees est suffisamment récent.

## Historique

**Alt+Left** et **Alt+Right** reculent et avancent dans l'historique ; l'icône **Historique** liste les dernières personnes.

## Lieux, sources, doublons

La recherche de lieux et de sources ainsi que « Trouver les doublons » sont assurées par webtrees lui-même ; le menu **webtrees** ouvre les pages correspondantes dans le navigateur. Pour voir comment deux personnes sont apparentées, utilisez le tableau **Lien de parenté** (voir [Tableaux](hilfe:tafeln)).
