# webtrees dans le navigateur

wtWin est une fenêtre sur webtrees, pas un remplaçant. L'administration de l'arbre reste sur le site webtrees, et le programme vous y mène d'un clic.

## Le menu webtrees

Les entrées ouvrent la page webtrees correspondante dans le navigateur ; connectez-vous-y si on vous le demande.

- **Lieux** et **Sources :** les listes de l'arbre.
- **Fusionner des enregistrements**, **Trouver les doublons**, **Vérifier l'arbre généalogique**, **Corrections de données :** les outils d'administration (gestionnaires de l'arbre uniquement).
- **Exporter en GEDCOM** et **Importer un GEDCOM** (gestionnaires uniquement).

## Une personne dans le navigateur

**Fichier › Ouvrir webtrees dans le navigateur** ouvre la personne actuelle (ou la page d'accueil) ; **Personne › Ouvrir dans webtrees** et le menu du clic droit font de même. Sur la fiche individuelle, **Modifier dans webtrees** mène directement à la page de la personne.

## Ce qui reste dans webtrees

- Utilisateurs, droits, réglages de confidentialité et approbations
- Modules, apparence du site, langue du site
- Modifier les noms, créer et lier des sources et des objets médias, modifier les notes
- Sauvegardes du serveur

## Modifications faites dans le programme

Ce que vous modifiez dans wtWin se trouve immédiatement dans webtrees, sous votre compte et avec ses droits. Si l'arbre est réglé sur « accepter automatiquement les modifications », elles s'appliquent tout de suite ; sinon elles attendent comme modifications en attente l'intervention d'un modérateur. Les modérateurs voient les modifications en attente dans la section **Accueil** et les y acceptent ou les refusent. **F5** recharge l'arbre après une modification faite dans le navigateur.
