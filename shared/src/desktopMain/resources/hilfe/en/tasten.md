# Keyboard shortcuts

## Main window

| Key | Action |
| - | - |
| F1 | Help |
| F5 | Reload tree |
| Ctrl+F | Go to (find person) |
| Ctrl+E | Edit person (person sheet) |
| Ctrl+N | Add relative |
| Ctrl+Enter | Selected person as central person |
| Alt+Home | Start person |
| Alt+Left / Alt+Right | Back / forward in history |
| Ctrl+D | Bookmark / remove bookmark |
| Ctrl+B | Bookmarks |
| Ctrl+Shift+C | Copy person text |
| Ctrl+P | Print person sheet |
| Ctrl+T | Descendant chart |
| Ctrl+Shift+T | Ancestor chart |
| Ctrl+Shift+P | Plausibility check |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | Section Home / Tree / Photos |
| Ctrl+Q | Quit |

## Person sheet

| Key | Action |
| - | - |
| Page Up / Page Down | Previous / next person in the list |
| Ctrl+Home / Ctrl+End | First / last person |
| Double-click on a row | Edit event |
| Esc | Close |

## Chart preview

| Input | Action |
| - | - |
| Mouse wheel | Zoom around the pointer |
| Drag | Pan |
| Click | Whole sheet / reading size |
| Right-click on a box | Colour or hide the branch |
| Esc | Close window |

## Navigator and tree

| Input | Action |
| - | - |
| Click | Person becomes central person |
| Double-click | Person sheet |
| Right mouse button | As central person, edit, bookmark, open in webtrees |
| Mouse wheel (tree in the centre) | Zoom |

**Esc** closes every window, including this help. The shortcuts are also shown in the menus next to the entries.
