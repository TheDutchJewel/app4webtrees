# Erscheinungsbild

| Datei | Inhalt |
|---|---|
| `wtwin-ci.tex` → `bauen.sh` → `build/wtwin-ci.pdf` | Namen, Logo, Farben, Schrift, Sprache, Anwendungen |
| `wtwinci.sty` | LaTeX-Paket mit Farben, Schriften, Titelseite, Tasten- und Hinweis-Bausteinen (LuaLaTeX) |
| `logo/` | Zeichen, Wortmarke und Varianten als SVG, PNG per `logo/rendern.sh` |

Farben und Begriffe kommen aus dem Programm (`ui/Theme.kt`, Menüs, Hilfe); Änderungen dort werden hier nachgezogen.
